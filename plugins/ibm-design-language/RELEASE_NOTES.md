# IBM Design Language 1.1.5

Stable package prepared locally from verified 1.1.5-rc.2. Not installed or published.

## Release summary

- Adds the visual casebook: five before/after studies, 15 documented decisions, five transfer exercises, ten HTML studies, 40 rendered images, an offline viewer and licensed IBM Plex fonts.
- Integrates the repaired evaluator, portable fixtures, recorded runtime options and an explicit individual-file artifact contract with accurate validation errors.
- Updates evaluation and coverage guidance while preserving the 21 bundled cases and 121 assertions.

## Promotion and validation

Only the plugin version and these release notes change from rc.2. Every skill file, evaluator, case, casebook asset and reference is byte-identical to the validated candidate. The 41 passing synthetic tests and existing rendered casebook checks are reused; local package and integrity checks verify this promotion. No additional model runs were made.

Measured design improvement remains unproven. The six-attempt comparison evaluated frozen rc.1: two scorable pairs tied and the third was incomplete after a baseline usage failure. Host configuration changed during run 2. These results do not constitute a new model evaluation of stable 1.1.5. Fresh packets are required for future authorized runs.

Installed 1.1.4 and the preserved, discovery-disabled standalone skill remain unchanged. This release preparation includes no installation, commit or publication.
