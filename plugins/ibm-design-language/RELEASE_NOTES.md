# IBM Design Language 1.1.9

Adds reviewed spatial-workspace and prototype-intake guidance to the canonical plugin, with wrapped-heading checks and component-specific modal rules. Preserves implementation assets, the casebook, evaluator and frozen historical releases.

Status guidance keeps requested circular geometry while making distinct internal symbols the recommended implementation; an explicit plain-dot constraint remains respected and labeled as a departure from that pattern. Page-level primary emphasis now follows the task: a monitoring or read-only page may need none. Untested container choices name the evidence that would change them.

Bundled eval cases 2, 4 and 7 correct older blanket rules; their final acceptance criteria remain unchanged from the 1.1.7 candidate. Three separate intake cases cover spatial workspaces, prototype adoption and typography. The 1.1.9 typography criterion clarifies that its guidance prompt asks for a verification plan, not an unperformed render. Older criteria and failures remain preserved.

Validation and exact outcomes are recorded in repository evidence/1.1.9-completion/REPORT.md; earlier iterations remain in evidence/1.1.8-targeted/. Targeted single-run results are not a general-quality certification. CLI logs do not independently establish every claimed image inspection; rendered, installed and source checks are reported separately. Publication status, immutable commit and release checksums belong to the GitHub release record.
