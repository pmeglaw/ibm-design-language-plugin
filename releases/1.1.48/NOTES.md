# 1.1.48 Table navigation and action guidance

Separate collection navigation (pagination, load more and continuous browsing)
from virtualization as a rendering strategy. Preserve frequently used secondary
actions, with overflow reserved for less frequent contextual commands.

Add scoped acceptance guidance for selection across rendered windows, navigation
recovery, keyboard/focus behavior and action discovery. Distinguish semantic
tables from interactive grids and respect batch-mode action restrictions.

No runtime assets, dependencies, product code, historical evaluation contracts
or fixture assertions change. Earlier frozen releases remain unchanged.
Static guidance regressions and existing browser fixtures do not establish
model-generated product quality or assistive-technology certification.
Publication and destination installation require separate verification.
